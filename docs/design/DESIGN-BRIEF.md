# תדריך עיצוב: שיר היום

## חמש השורות (תורת התקשורת החזותית, שלב א)
1. **מסר:** שיר אחד ביום הוא משפט שמזיז אותך לצעד קטן היום.
2. **קהל והחלטה:** אישה שפותחת את האפליקציה בבוקר, ומחליטה אם לעשות חמש דקות לעצמה.
3. **סוג המידע והייצוג:** מסר (משפט) בטיפוגרפיה גדולה, תחום (צבע משמעותי), וזמן (תאריך כציר יומי).
4. **מוקד:** המשפט של היום, גדול, על פוסטר אחד.
5. **סירקולציה:** מהפוסטר לשיר, מהשיר לתרגול. בטיוטה, מהיום ליומן ובחזרה.

## DNA
- **חומר:** נייר לבן, דיו שחור, מרקר צהוב אחד לכל משפט מרכזי.
- **קצב:** רווחים 4/8/16/24/32 בלבד.
- **אור:** קו דק וחד, בלי צללים דקורטיביים.
- **צורה:** קשתות קונצנטריות של התחום, שמצטברות לאורך הזמן (יום אחרי יום).
- **תנועה:** קשת אחת נשרטת פעם אחת בכניסה, ונעצרת. בלי ליטופים חוזרים.
