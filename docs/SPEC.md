# אפיון: שיר היום (שם עבודה)

## בעיה ומטרה
נשים רבות רוצות הרגל קטן של העצמה, אבל אין להן זמן או מסגרת. האפליקציה נותנת שיר אחד ביום, ותרגול של חמש דקות שמחבר את המסר של השיר לפעולה אחת בעולם האמיתי.
המשתמשת צריכה להרגיש אחרי חמש דקות: עשיתי משהו קטן בשבילי, והוא נשאר.

## משתמשת ותרחיש
- משתמשת: אישה שמוכנה לחמש דקות ביום, בעברית, בטלפון.
- פעולה ראשונה: פותחת את האפליקציה, רואה את שיר היום ואת המסר במשפט אחד.
- פעולה שכיחה: לוחצת "התחל תרגול", עוברת שלושה שלבים (האזנה, כתיבה, הצהרה), וסוגרת "סיימתי היום".

## מסלול מרכזי
1. היום: שיר היום, המסר, כפתור "התחל תרגול".
2. תרגול, שלושה שלבים:
   - האזנה: קישור להאזנה חיצונית. לא מטמיעים נגן ולא מציגים מילים מלאות.
   - כתיבה: דקה שלוש, עם טיימר ושדה כתיבה שנשמר אוטומטית. יש הקלטה ותמלול בעברית, כשהדפדפן תומך.
   - הצהרה: משפט מפתח גדול, שהמשתמשת אומרת לעצמה בקול.
3. סיום: סימון "בוצע", מד התקדמות שבועי, רצף ימים, ושיתוף.

## רשימת מסכים
| מסך | מטרה | פעולה ראשית |
|---|---|---|
| היום | להציג את שיר היום ואת המסר | התחל תרגול |
| תרגול | לבצע את שלושת השלבים | הבא / סיימתי היום |
| יומן | לראות את היסטוריית התרגולים והכתיבה | לחיצה על יום |
| הוספת שיר | להוסיף שיר ותרגול לאוצרת | שמור שיר |

## מידע נשמר (localStorage, בלי שרת)
- `Entry`: תאריך, מזהה שיר, האם בוצע, הכתיבה, האם נאמרה ההצהרה, זמן סיום.
- `customSongs`: שירים שנוספו באפליקציה.
- שיר היום נגזר מהתאריך ומרשימת השירים, כך שכל המשתמשות באותו יום רואות את אותו שיר.

## מוצר מינימלי (MVP בקוד הזה)
- שני שירים בתוכן ההתחלה, כדי להוכיח את הזרימה. הנתונים האלה טיוטה, והאוצרת צריכה לאמת אותם.
- שלושת השלבים, טיימר, שמירה אוטומטית, הקלטה ותמלול, מד שבועי, רצף, שיתוף, יומן והוספת שיר.

## מה האפליקציה לא עושה (בשלב הזה)
- אין מנוי, תשלום, קהילה או פלייליסטים. אלה שלבים הבאים במודל העסקי.
- אין התראה של 07:00 כ-push אמיתי. הכפתור "תזכורת" פועל רק כשהלשונית פתוחה, ושירות push דורש Firebase.
- אין מילות שירים מלאות. זה תוכן מוגן זכויות, ולכן מציגים מסר ולא טקסט.
- אין AI ביצירת תרגולים. בשלב הבא: Edge Function עם Gemini, ותקן הזיקוק מ-`docs/ai-text-standard.md`, ובקרת איכות של אוצרת.
