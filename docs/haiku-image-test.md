# ניסוי: הייקו ותמונה לכל שיר

## מה נבדק
האם כדאי לצרף לכל שיר גם הייקו וגם תמונה.
הניסוי רץ על שני השירים שבתוכן ההתחלתי.

## מה נבנה באפליקציה
- **הייקו**: שדה `haiku` בכל שיר, שלוש שורות של 5, 7 ו-5 הברות. כתיבה מקורית, לא מילות השיר.
- **תמונה גנרטיבית**: נבנית בדפדפן מהשיר עצמו. הצורה נגזרת מהמזהה, והצבע מהנושא. כל שיר מקבל תמונה, גם שיר שמשתמשת מוסיפה, בלי שירות חיצוני ובלי עלות.
- **פרומפט לתמונה מצולמת**: למטה, לבדיקה במידג'רני. אם התמונה המצולמת עדיפה, מעלים אותה ל-`public/art/<id>.jpg` ומחברים שדה `image`.

## הערכה (לא עובדה)
- ההייקו מוסיף **שכבה רגשית בשלוש שורות**, ותופס מעט מקום. כדאי לכל שיר.
- התמונה הגנרטיבית נותנת **זהות חזותית לכל שיר בלי עלות**, ומחזקת את צבע הנושא.
- תמונה מצולמת חזקה יותר רגשית, אבל דורשת יצירה ידנית לכל שיר. מומלץ רק לשירים מאושרים.
- דרך בדיקה: להציג לחמש משתמשות את שני המצבים, ולמדוד אם המסר נזכר למחרת.
