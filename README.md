# שיר היום

שיר אחד ביום, ותרגול של חמש דקות שמחבר את המסר של השיר לפעולה אחת בחיים.

## הרצה מקומית

```bash
npm install
npm run dev
```

## בדיקה ובנייה

```bash
npm run build
npm run preview &
npm run test:e2e
```

## מבנה

- `src/data/songs.json`: תוכן התחלתי. הנתונים מסומנים `verified: false` עד לאימות אוצרת.
- `src/lib/store.ts`: שמירה ב-localStorage, שיר היום לפי תאריך, רצף וחישוב שבועי.
- `src/App.tsx`: מסכים: חזון (פתיחה), היום, תרגול (שלושה שלבים), יומן, הוספת שיר.
- `src/components/`: חזון, תמונה גנרטיבית לשיר, אקולייזר, כפתור הקלטה, אייקונים.
- `docs/haiku-image-test.md`: ניסוי הייקו ותמונה לכל שיר, עם פרומפטים למידג'רני.
- `docs/SPEC.md`: אפיון, מה נכלל ומה לא.
- `tests/e2e.mjs`: בדיקת עשן בדפדפן, בנייד ובטאבלט קטן.
